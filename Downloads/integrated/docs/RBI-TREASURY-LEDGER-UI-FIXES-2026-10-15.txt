RBI, TREASURY AND LEDGER UI FIXES
15 October 2026

Both UI issues from the full check are fixed and loaded in the local app.

TREASURY WORK OWNERS
The owner dropdown now uses a treasury-specific directory. Eligible users must
be active employees with an active, currently effective global role granting
TREASURY_RECONCILE or TREASURY_WORK_APPROVE. Customers, disabled users and
expired or future assignments are excluded. The directory returns only user
IDs and usernames and does not require general IAM user-directory access.
Work creation checks eligibility again and rejects an invalid or stale owner
with HTTP 422 / INVALID_WORK_OWNER before inserting the work item.
The live dropdown contains admin, checker, checker1 and mcp_demo_checker.

JOURNAL AND EVIDENCE INQUIRIES
Journal balance control now offers the existing journals in a dropdown with
their journal type, value date and description. Settlement evidence inquiries
offer actual evidence records with their external settlement reference,
status and amount. The same reference sources support journal/evidence ID
fields in related operations. Record ID mapping selects the journal/evidence
identifier rather than a related account or owner identifier.
New reference APIs retain the corresponding staff access checks; customer and
anonymous access is denied. The evidence list and detail inquiry have distinct
operation labels.
